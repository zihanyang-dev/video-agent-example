# 已撤回：合并 server 与 agent 的方案

状态：已撤回，未实施。日期：2026-09-21。

当前推荐架构见 [四个独立应用，清晰的模型与数据归属](./2026-09-21-four-app-architecture.md)。

原方案将 agent 代码并入 server，使用 HTTP 与 worker 两个入口运行。这一代码边界决定已撤回：agent 具有独立的执行规则、模型适配、沙箱管理和运行生命周期，应保留为独立应用。

新版保留应用内领域分层、依赖倒置、按用例组织和受控共享包；通过明确的数据归属、命令与结果协议解决跨应用协作，不通过合并应用回避这些边界。

本文件只保留撤回记录，不再作为目录或迁移指南。
